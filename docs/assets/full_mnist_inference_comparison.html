Takeaway: this is not a claim that TensorPy beats PyTorch everywhere. It shows that, in this specific full-MNIST CNN inference benchmark, an AI-native runtime with integrated data ingress, tensorization, and execution can outperform a larger layered stack on both pure forward latency and end-to-end cost.
